Objective

To design and implement a low cost, short range visible light data transmission system in which
text data is transmitted through rapidly modulated light from a smartphone flashlight, received
using an LDR based receiver, decoded using an ATmega328P microcontroller, and displayed on
an LCD.

Project Idea & Approach

LiFi (Light Fidelity) is a wireless communication technology that uses visible light to transmit
information. Unlike conventional wireless communication systems that use radio-frequency
signals, LiFi uses rapidly varying light emitted from a light source such as an LED. These
variations in light intensity occur at a sufficiently high speed that they are not noticeable to the
human eye, while an appropriate light sensor can detect and interpret them.
The basic principle of LiFi based data transmission is similar to digital communication.
Information is converted into a sequence of binary data, represented by changes in the state of
the light source. For example, the light being switched ON and OFF in a predefined pattern can
represent a sequence of binary bits. At the receiver, a light sensitive device detects these
changes and converts them into electrical signals. The received electrical signals are then
processed to reconstruct the original information.
In this project, we propose to develop a low cost, short range visible light data transmission
system using a smart phone as the transmitter and an LDR based electronic circuit as the
receiver.
The smartphone will run a LiFi transmitter application. The user can enter a text message into
the application, and the application converts the message into a sequence of light variations.
The smartphone flashlight acts as the optical transmitter and rapidly changes its light output
according to the encoded data.
The transmitted light travels through free space and is received by an LDR (Light Dependent
Resistor) positioned towards the smartphone flashlight. The resistance of the LDR changes
according to the intensity of the incident light. Therefore, the rapid changes in the flashlight
produce corresponding changes in the electrical signal generated by the LDR circuit.
The LDR output is then provided to the receiver electronics, where the signal is conditioned into
a form that can be reliably interpreted by the microcontroller. An ATmega328P microcontroller is
used as the main processing unit. It detects the received light pulses, interprets the timing or
pattern of the pulses according to the communication protocol, reconstructs the transmitted
data, and converts it back into readable text.
The decoded text is finally displayed on a LCD, allowing the user to directly observe the
message received through the visible-light communication channel.

The proposed system can be divided into the following stages

Text Input → Data Encoding → Light Transmission → Light Detection → Signal
Conditioning → Data Decoding → LCD Display

Why This Approach is Chosen

The proposed system is intended as a simple and low cost demonstration of visible-light
communication. A smartphone is used as the transmitter because it already contains a
controllable LED flashlight and can run an application for encoding the text message. This
eliminates the need to design a separate high power optical transmitter.
An LDR is selected as the receiving element because it is inexpensive, easily available, and
capable of detecting changes in light intensity. The ATmega328P provides sufficient processing
capability for decoding the relatively simple data signal, while the LCD provides an immediate
visual representation of the received information.
The complete receiver can be assembled on a perfboard, making the system compact and
inexpensive.

Expected Outcome

The expected outcome of the project is a functional short range visible light communication
prototype capable of transmitting a text message from a smartphone flashlight to an LDR based
receiver. The received optical signal will be converted into an electrical signal, decoded by the
ATmega328P, and displayed as readable text on the LCD.

The project will demonstrate the fundamental concept of transmitting digital information through
rapidly varying visible light without using a conventional wired communication connection.

Complete Process

● The user enters a text message into the LiFi transmitter application installed on a
smartphone.
● The application converts the text message into a predefined sequence of binary data.
● The smartphone flashlight is controlled according to this data sequence. The flashlight
rapidly varies between different light states to represent the transmitted information.
● The light pulses travel through the air and reach the LDR sensor placed at the receiver.
● The LDR detects the variations in light intensity and produces a corresponding electrical
signal.
● The signal is processed or conditioned so that the ATmega328P can distinguish the
transmitted light states reliably.
● The ATmega328P receives the signal and decodes the sequence of light pulses
according to the defined communication protocol.
● The decoded binary information is converted back into characters and reconstructed as
the original text message.
● The received message is displayed on a LCD.
● Receiver Circuit Approach.
● The receiver will be constructed as a standalone circuit on a perfboard using a bare
ATmega328P microcontroller.

The major sections of the receiver circuit are:

LDR Sensor → Signal Conditioning → ATmega328P → LCD
The LDR will be connected as part of a voltage divider circuit so that changes in light intensity
produce corresponding voltage changes. Since the raw output from an LDR is an analog signal
and may be affected by ambient lighting and noise, a signal conditioning stage can be used to
convert the detected variations into cleaner electrical pulses before they are supplied to the
microcontroller.

The ATmega328P acts as the central processing unit of the receiver. It monitors the signal from
the LDR circuit, determines the transmitted light states, decodes the received data, and sends
the resulting characters to the LCD.
A regulated power supply circuit will provide the required operating voltage to the
microcontroller, LCD, sensor, and other receiver circuitry. Suitable resistors and decoupling
capacitors will be included to ensure proper operation and electrical stability of the circuit. Push
buttons are provided for functions such as resetting the microcontroller or controlling the
receiver, while LEDs can be used as power or data status indicators.

Applications

● Hospitals & operation theatres : RF signals can interfere with MRI machines,
pacemakers, and monitoring equipment. Light based data doesn't, so LiFi lets
staff transmit patient data wirelessly near sensitive devices safely.
● Aircraft cabins : Airlines restrict RF use during flight for interference reasons. LiFi
through cabin LED lighting could let passengers get in flight connectivity without
touching RF spectrum.
● Underwater communication RF is basically useless underwater, but light travels
reasonably well. Used in underwater submarines short range comms where fibre
optic cables are impractical.
● Petrochemical plants, mines, oil rigs : RF transmitters can spark and ignite
flammable gases. Li-Fi is intrinsically safer since light based transmission doesn't
carry that ignition risk.
● Spectrum congested dense areas : Wi-Fi's RF spectrum is crowded in stadiums,
malls, airports. Every LED light fixture (streetlights, ceiling lights) can double as a
data access point, massively increasing available bandwidth without touching RF
spectrum at all.
● High security rooms : Since light doesn't pass through walls, data physically can't
leak outside the room the way Wi-Fi signals do. Useful for banks, defense, and
data centers wanting locally contained wireless networks.
